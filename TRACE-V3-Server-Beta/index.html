The method

Actual machine learning.
Clear limitations.

We use an existing public TF-IDF + logistic-regression text classifier, not invented pattern percentages. It was trained on older generated text, so modern, mixed, edited, or non-English writing can be misclassified. This is a technical beta, not an academic misconduct tool.

Questions

What you should know.

Is this an accurate AI detector?

Not yet. It uses an existing trained text classifier, but we have not benchmarked it on independent modern writing samples. A model signal is not proof of authorship.

Does TRACE store my text?

This website has no TRACE backend or database. Inference happens in your browser after downloading the model. Avoid uploading sensitive documents to any untrusted website.

Why does the first scan take time?

Your browser must download a machine-learning model (around 126 MB plus supporting files) before it can run the first prediction. Later visits may benefit from browser caching.

What about students who use grammar tools?

The current model cannot reliably separate legitimate assistance, edited writing, and fully AI-generated writing. Interpretation requires human context.
